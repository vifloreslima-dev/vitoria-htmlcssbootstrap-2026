O que é Bootstrap?

Bootstrap é um framework front-end de código aberto usado para criar interfaces de sites e aplicações web de forma rápida e responsiva. Ele fornece um conjunto de componentes prontos e estilos em CSS, além de recursos em JavaScript.

O que o Bootstrap oferece?

Sistema de grid (grades): facilita organizar o conteúdo da página em colunas que se adaptam a diferentes tamanhos de tela.

Componentes prontos: botões, menus de navegação, formulários, tabelas, cards, modais, alertas, entre outros.

Design responsivo: o layout se ajusta automaticamente para celulares, tablets e computadores.

Classes utilitárias: permitem alterar espaçamentos, cores, alinhamentos e tamanhos sem escrever muito CSS.

IW-1: Perguntas sobre Doramas

Os K-dramas (onde o "K" vem de Korean) são as produções televisivas produzidas na Coreia do Sul. Embora o termo geral "dorama" tenha nascido da pronúncia japonesa para a palavra drama, no Brasil ele acabou virando um apelido carinhoso para séries de vários países asiáticos, sendo as sul-coreanas bastante populares.

OST significa Original Soundtrack, ou trilha sonora original. Nos doramas, as OSTs são músicas criadas ou selecionadas especialmente para a produção, ajudando a transmitir as emoções de cada cena.

Na Coreia do Sul, o termo "Oppa" (오빠) é usado por mulheres para se referirem a homens mais velhos da mesma geração, como irmãos, amigos próximos ou namorados. É uma palavra que pode demonstrar carinho, respeito e intimidade, dependendo do contexto.
